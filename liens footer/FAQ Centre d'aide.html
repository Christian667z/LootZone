🛒 Commandes & Achats

Comment passer une commande sur Asta-Shops ? ▾
Pour passer une commande, sélectionnez le produit souhaité dans notre catalogue, choisissez la dénomination (montant), entrez votre identifiant de jeu (UID/ID), sélectionnez votre méthode de paiement et confirmez. La livraison est instantanée après validation du paiement.
Comment trouver mon UID/ID de jeu ? ▾
L'UID (User ID) se trouve généralement dans les paramètres de votre jeu ou sur votre profil en jeu. Pour Free Fire : Profil → votre ID s'affiche → Vous copier → le coller à l'endroit où on vous demande de mettre votre id. Pour PUBG Mobile : Profil → votre ID s'affiche sous votre pseudo. Pour Roblox : votre URL de profil contient votre ID.
Puis-je annuler une commande après paiement ? ▾
Les commandes de produits numériques (crédits jeux, cartes cadeaux) ne peuvent généralement pas être annulées après livraison car le produit est déjà utilisable. Si votre commande est encore en cours de traitement, contactez immédiatement notre support via WhatsApp. D'autre moyens pour nous contacter sera disponible plus tard.

💳 Paiement

Quels moyens de paiement acceptez-vous ? ▾
Nous acceptons Moncash et Natcash en paiement principal. Les paiements par carte bancaire (Visa, Mastercard) et portefeuilles numériques sont également disponibles selon votre région. D'autres méthodes sont en cours d'intégration.
Mon paiement a été débité mais je n'ai pas reçu mon produit. Que faire ? ▾
Si votre paiement a été confirmé mais que vous n'avez pas reçu votre produit dans les 30 minutes, contactez notre support via WhatsApp (ou un ticket directement dans le site) en fournissant votre numéro de commande et une capture d'écran de la confirmation de paiement. Nous réglons ce type de situation sous 24 heures maximum.
Les paiements sur Asta-Shops sont-ils sécurisés ? ▾
Oui, absolument. Toutes les transactions sur Asta-Shops sont sécurisées par un protocole SSL/TLS. Nous ne stockons aucune donnée bancaire sur nos serveurs. Chaque transaction est vérifiée et tracée pour garantir votre sécurité financière.

⚡ Livraison

Dans quel délai vais-je recevoir mon produit ? ▾
La livraison est quasi-instantanée pour la majorité des produits (moins de 5 minutes après confirmation du paiement). Dans de rares cas (forte demande ou vérification manuelle), le délai peut être de 5 à 30 minutes. Vous serez notifié par e-mail.
Comment est livré mon produit ? ▾
Les crédits jeux sont crédités directement sur votre compte de jeu via votre UID. Les cartes cadeaux et clés sont envoyées par e-mail et également disponibles dans votre espace client sous "Historique des achats".

🔄 Remboursements

Dans quels cas puis-je obtenir un remboursement ? ▾
Un remboursement peut être accordé si : le produit n'a pas été livré dans le délai annoncé, un code activé est défectueux ou invalide, ou si une erreur technique de notre côté est confirmée. Chaque demande est examinée individuellement par notre équipe.
Comment soumettre une demande de remboursement ? ▾
Contactez notre support via WhatsApp ou à support@asta-shops.com dans les 48 heures suivant votre achat. Fournissez votre numéro de commande, l'email utilisé et une description du problème. Notre équipe vous répondra sous 24 heures ouvrées.
